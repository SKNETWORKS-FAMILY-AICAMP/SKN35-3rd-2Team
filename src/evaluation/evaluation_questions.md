# AI 개발 도우미 평가 질문표

작성일: 2026-10-08. 이 표는 평가 계획이며, 실제 성능 측정 결과가 아닙니다.

## 사용 방법

1. 아래 질문을 앱에 입력하고 실제 답변을 기록합니다.
2. 기대 답변과 근거 문서를 비교합니다. 문서 경로는 프로젝트 루트 기준입니다.
3. 정확성, 근거, 환각 방지를 각각 0~2점으로 기록합니다.
   - 정확성: 0=틀림, 1=일부 맞음, 2=필수 내용을 모두 설명함.
   - 근거: 0=없거나 잘못된 출처, 1=관련 출처지만 주장 연결 부족, 2=주장을 뒷받침하는 확인 가능한 출처.
   - 환각 방지: 0=없는 사실/실행 결과를 단정, 1=불확실성을 일부만 표시, 2=근거 없는 단정 없이 한계를 설명함.
4. 합계보다 실패 원인을 기록하세요. 기능이 미구현이면 0점 대신 '평가 대기'로 표시합니다.

현재 연습 모드는 UI 확인용이며 답변 품질 채점 대상이 아닙니다. OpenAI/NVIDIA 모드에서는 일반 답변만 확인할 수 있습니다. RAG, MCP, 이미지 분석 평가는 해당 기능 연결 후 진행합니다.
