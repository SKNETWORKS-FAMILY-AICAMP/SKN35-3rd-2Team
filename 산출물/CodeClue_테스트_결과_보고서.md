# CodeClue 테스트 결과 보고서

개정일: 2026년 10월 14일 / 기존 작성일: 2026년 10월 12일 대상 기록: 2026년 10월 11~12일에 수행한 평가와 검사

## 1. 테스트 목적과 개정 범위

수업 지표인 Hit@K / Recall@K / Faithfulness로 RAG 검색과 근거 충실성을 평가하고, MCP는 도구 선택 / 인자 / 실행, 멀티모달은 이미지 인식 / 진단을 보완 평가하도록 보고 체계를 개정했습니다. 지표의 계산과 데이터 구성은 수정 계획서에 정의합니다. 이번 개정은 첨부 문서의 기존 기록을 재구성한 것입니다. 새 AI 호출 / 도구 실행 / 이미지 인식 평가를 수행하지 않았습니다. 과거 결과와 새 평가 계획을 구분하며, 문서 개정일을 실제 시험일로 사용하지 않습니다.

### 기존 평가 목적

CodeClue가 개발자의 LangChain / LangGraph / MCP 오류를 이해하고, 따라 할 수 있는 해결 방법과 참고 자료를 제공하는지 확인했습니다. 오류 질문에 대한 실제 AI 답 변과 앱 내부 기능 검사 결과를 각각 정리했습니다.

## 2. 전체 결과

앱 내부 자동 검사 212개는 통과했습니다. 그러나 실제 AI 답변에는 잘못된 코드와 근거 없는 설명이 있었고, 일부 질문은 답변을 받지 못했습니다. 따라서 오류 해결 도우 미로서 전체 검증을 완료했다고 판단할 수 없습니다.

| 구분 | 확인한 결과 | 의미 |
| --- | --- | --- |
| 실제 AI 답변 | 설치 오류 안내는 대체로 적절했다. 반복 종료 설명, 후속 코드, 내부 오류 설명에는 문제가 있었다. | 핵심 답변 품질을 개선하고 다시 평가해야 한다. |
| 앱 내부 자동 검사 | 212개 통과 | 검사한 입력 처리 / 저장 / 도구 연결 등은 해당 테스트 조건에서 정상 동작했다. |
| 전체 사용 흐름 | 이미지 / 외부 도구 / 브라우저 저장 복원 등은 확인이 남았다. | 개별 기능 검사만으로 실제 앱 전체가 정상이라고 판단할 수 없다. |

이 문서는 기존 실행 기록을 정리한 보고서입니다. 문서 작성 중 새 AI 질문이나 앱 테스트를 실행하지 않았습니다. 아래 기능 상태는 당시 기록 기준이며, 이후 변경한 앱 은 다시 확인해야 합니다.

## 3. 새 평가 체계의 측정 현황

기존 문서에 정답 근거 집합 / 검색 순위 / 답변의 주장별 근거 판정 / 이미지 정답 항목이 없어 새 지표의 수치를 산출하지 않았습니다. 과거 실패 사례만으로 Faithfulness 를 0점이나 임의 비율로 환산하지 않습니다.

| 평가 대상 | 지표 | 현재 결과 | 추가로 필요한 증거 |
| --- | --- | --- | --- |
| RAG 검색 | Hit@1/3/5, Recall@1/3/5 | 미측정 / 평가 가능 수 미집계 | 질문별 정답 근거 ID와 검색 순 위 / ID / 본문 |
| RAG 답변 | Faithfulness | 미측정 / 평가 가능 수 미집계 | 최종 답변의 주장과 실제 전달 근거 대조 |
| MCP 선택 / 호출 | 선택 정확도, 인자 정확도, 실행 성공률 | 미측정 / 평가 가능 수 미집계 | 기대 도구 / 인자와 실제 호출 / 결과. 정상/의도적 실패 분리 |
| MCP 답변 | 결과 기반 Faithfulness, 실패 대응 성공률 | 미측정 / 평가 가능 수 미집계 | 도구 반환값 / 오류와 최종 답변 |
| 멀티모달 | 핵심 정보 인식 / 진단 정확도 | 미측정 / 평가 가능 수 미집계 | 원본 이미지, 판독 가능한 핵심 정답, 추출값 / 진단 |
| 멀티모달 후속 검색 | Hit@K, Recall@K, 문서 기반 Faithfulness | 미측정 / 평가 가능 수 미집계 | 이미지 분석 이후 검색 기록과 실제 답변 근거 |
| 서비스 품질 | 응답 성공률, 응답 시간 중앙값/p95 | 전체 집계 미완료 | 전체 시도 수, 정상 완료 수, 개별 시간 / 중단 기록 |

212개 자동 검사 통과는 위 지표의 측정값이 아닙니다. 로컬 MCP 연결 검사 8개 통과도 사용자 질문의 도구 선택 정확도나 실제 서비스 전체 호출 성공률을 뜻하지 않습 니다.

### 기존 실패 기록과 새 지표의 연결

| 기존 관찰 | 관련 평가 | 해석과 제한 |
| --- | --- | --- |
| 관련성이 낮은 문서로 답변 단계 진행 | Hit@K / Recall@K | 검색 개선 필요성을 시사하지만 정답 근거와 순위가 없어 수치 산출 불가 |
| 잘못된 import / API와 내부 오류 단정 | Faithfulness / 해결 정확성 / 코드 실행 | 근거 충실성과 실행 가능성 재검증 필요. 주장별 판정 없이 점수 확정 불가 |
| 시간 초과 / 오류 안내 | 응답 성공률 / 시간 / 실패 대응 | 실행한 실패 사례로 보존. 정상 답변 미생성은 Faithfulness N/A |
| 이미지 처리 / 도구 단위 검사 통 과 | 이미지 인식 / MCP 실제 호출 평가 | 처리 코드의 동작 증거이며 실제 인식 / 답변 품질 평가와 구분 |

## 4. 실제 질문에 대한 답변 결과

계획서의 T 번호와 연결해 정리했습니다. 과거 질문은 새 계획서와 문구 / 검색 횟수 조건이 일부 다르므로, 새 계획의 통과 결과로 대체하지 않습니다.

| 관련 항목 | 날짜 / 시험 내용 | 실제 결과 | 판정 |

| T02 LangChain 입력 오류 | context 누락 질문 | 이 보고서에서 판정할 실제 답변 기록을 확보하지 못했다. | 확인 필요 |

## 8. 최종 판단

CodeClue는 입력 처리, 저장, 로컬 도구 연결 등 내부 기능의 기본 동작을 확인했습니다. 하지만 앱의 핵심 목적인 정확하고 실행 가능한 오류 해결 안내는 추가 개선과 재 시험이 필요합니다. 다음 평가에서는 T01~T07의 실제 답변을 저장하고, 제시한 코드를 실행해 확인해야 합니다. 참고 자료와 이미지 / 도구 / 저장 기능도 실제 사용자 화면에서 끝까지 확인 한 뒤 최종 결과를 갱신합니다.

## 9. 재평가 및 개선 전후 비교 양식

수정 계획서의 초기 권장 구성은 RAG 30개, MCP 15개, 멀티모달 15개입니다. 이는 실행 예정 구성으로, 확보된 실제 평가 데이터나 완료 결과가 아닙니다. 기존 T 번호와 신규 사례 ID를 연결해 중복 집계를 방지합니다.

| 비교 항목 | 개선 전 | 개선 후 | 함께 보고할 내용 |
| --- | --- | --- | --- |
| Hit@1/3/5 / Recall@1/3/5 | 미측정 | 미측정 | 정답 근거가 있는 평가 질문 수, 검색 실패 / 미실행 수 |
| Faithfulness | 미측정 | 미측정 | 답변 평가 가능 수, 미생성 / N/A 수, 사람 검토 결과 |
| MCP 선택 / 인자 / 실 행 / 실패 대응 | 미측정 | 미측정 | 지표별 분모, 정상/의도적 실패 구분, 호출 로그 |
